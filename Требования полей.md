# Требования экрана Me

Полные продуктовые требования к **странице Me**: layout, тексты, все кнопки/контролы и их состояния, а также правила полей ввода.  
При изменении Me — обновлять этот файл (и при необходимости OpenSpec `me-screen`).

В конце — отдельно правила поля заметки на **Partner** (связанный ввод).

---

# 1. Назначение страницы

Пользователь на вкладке Me:

1. видит приветствие и текущее настроение;
2. выбирает одно из 6 настроений;
3. выбирает готовый wish или пишет свой;
4. нажимает **Share with partner** (локально, без сети);
5. видит реакцию партнёра на своё настроение (если есть);
6. просматривает **My mood this week**.

Визуал 1:1 с Figma Make Main app → Me (`design-reference`). Копирайт UI — английский.

---

# 2. Общие правила страницы

| Тема | Требование |
|------|------------|
| Данные | Всё на устройстве; без сервера и обязательного аккаунта |
| Сессия | Mood/wish/history живут при смене табов в рамках процесса |
| Persistence | Disk sync пока не требуется (после kill app допустим сброс) |
| Фон | Мягкий светлый canvas + цветные ambient-блобы |
| Mood tint | При выбранном mood ambient окрашивается цветом этого mood |
| Карточки | Frosted glass (не плоские opaque-блоки) |
| Скролл | Вертикальный ScrollView; контент не прячется под floating tab bar |
| Клавиатура | Поле wish и Share остаются доступны; tab bar можно скрывать |
| Design System | Цвета / glass / фон / метрики из `DesignSystem/`; без копипаста hex |

# 3. Структура страницы (сверху вниз)

| # | Блок | Тип | Когда виден |
|---|------|-----|-------------|
| 1 | Greeting | текст | всегда |
| 2 | `How are you feeling?` | заголовок | всегда |
| 3 | Current mood panel | glass-карточка / кнопка | всегда |
| 4 | Hint над сеткой | текст | зависит от состояния (см. ниже) |
| 5 | Сетка 6 mood-сфер | кнопки 2×3 | всегда |
| 6 | `Your wishes...` + пресеты | кнопки-карточки | только если mood выбран |
| 7 | Поле `Or write your own…` | text field | только если mood выбран |
| 8 | Кнопка Share | primary CTA | только если mood выбран |
| 9 | `My mood this week` | glass-карточка + кнопки дней | всегда |
| 10 | Floating tab bar | навигация приложения | всегда (кроме открытой клавиатуры — можно скрыть) |

Порядок взаимодействия: greeting → current → pick mood → pick/write wish → Share → week.

---

# 4. Тексты и неинтерактивные элементы

### Greeting

- Формат: time-of-day + display name + опциональный emoji (пример: `Good night, Anna ✨`).
- Стиль: светлый/лёгкий шрифт, по центру.

### Заголовок

- Текст: `How are you feeling?`
- Крупный ultraLight / thin, по центру.

### Hint над сферами

- Когда mood **не** выбран и current пустой / после share: ориентир вроде  
  `Your partner would love to know how you're feeling`  
  или пустое приглашение выбрать mood (как в reference).
- Не кнопка.

### Заголовки секций

- Wishes: `Your wishes...` (мелкий, слева).
- Week: иконка календаря + `MY MOOD THIS WEEK` (uppercase, tracking, светло-серый).

# 5. Кнопки и контролы (полная матрица)

## 5.1 Current mood panel

| Состояние | Вид | Действие по тапу |
|-----------|-----|------------------|
| Пусто (ещё не делились) | Текст: `Select your mood below to share it with your partner` | **не** кнопка |
| Есть shared mood | Иконка-сфера mood · полное имя · wish · ⏱ дата/время · chevron `>` | открывает sheet истории реакций (если есть ответы / панель помечена tappable) |
| Есть реакция партнёра | + chip `{emoji} {PartnerName} reacted` · опционально note | тот же тап по панели → sheet |

**Chip реакции** — отображение, не отдельная кнопка отправки.  
**Chevron** — индикатор tappable, не отдельный control.

**Sheet «история реакций»**

- Диалог: твоя отправка **справа**, ответ партнёра **слева**.
- Закрытие: стандартный dismiss sheet (свайп / системный крестик).
- Отдельной кнопки Send внутри sheet нет.

---

## 5.2 Mood spheres (6 кнопок)

Сетка **2 ряда × 3**. Каждая сфера — кнопка.

| Элемент | Требование |
|---------|------------|
| Состав | Glow + градиентный круг + smoke-анимация + белая иконка + подпись под сферой (полное name mood) |
| Idle | Все сферы равноправны |
| Selected | Ярче, selection ring; ambient tint этого mood |
| Others when one selected | Приглушены (dim) |
| Тап по несchosen | Выбрать mood; сбросить предыдущий wish / custom text |
| Тап по уже выбранному | Снять выбор mood; скрыть wishes + Share; сбросить wish |
| Accessibility | Каждая сфера — button; стабильные id по mood |

Каталог (ровно эти 6):

| id | Name под сферой |
|----|-----------------|
| calm | Calm & Balanced |
| joy | Joy & High Energy |
| love | Love & Connection |
| sad | Sad & Vulnerable |
| exhausted | Exhausted & Low Battery |
| stressed | Stressed & Irritated |

Joy — тёплый жёлтый (без фиолетового wash).

---

## 5.3 Wish preset cards (3 кнопки)

Видимы **только** при выбранном mood.

| Состояние | Вид | Тап |
|-----------|-----|-----|
| Unselected | Glass card, текст idle-серый | Выбрать этот wish; очистить custom field; снять ошибку |
| Selected | Glass + tint цвета mood, текст темнее, обводка mood | Можно оставить выбранным; повторный тап не обязателен (достаточно одного выбранного) |

Подпись секции: `Your wishes...` — не кнопка.  
Тексты пресетов — из каталога (`MoodCatalog` / `needsByMood`); **не** валидируются алфавитом custom wish.

---

## 5.4 Custom wish field

См. подробно §7. Кратко как control:

| Состояние | Вид |
|-----------|-----|
| Empty | Placeholder `Or write your own…`, счётчик `0/80` |
| Typing / selected | Tint как у selected wish; счётчик `N/80` |
| At limit | Счётчик с акцентом (rose); новые символы не вводятся |
| Error after Share | Красная обводка + inline текст ошибки под полем |
| Focus | Клавиатура; Done закрывает; автоскролл к полю/Share |

Ввод в поле = этот текст становится выбранным wish (пресет снимается).

---

## 5.5 Кнопка Share with partner

Видима **только** при выбранном mood. Полная ширина, скругление ~18.

| Phase | Label / UI | Стиль | Можно нажать? |
|-------|------------|-------|----------------|
| `idle` | иконка paperplane + `Share with partner` | glass + tint mood | да (даже если wish пустой — тогда показать ошибку) |
| `idle` без «готового» wish | то же | opacity ~0.55 (визуально слабее) | да — для показа inline-ошибки |
| `sending` | spinner + `Sending...` | glass, приглушённый tint | нет (не button) |
| `sent` | checkmark + `Sent!` | **navy** fill, светлый текст | нет (не button) |

После `sent`:

1. запись в history + обновление current mood;
2. сброс selected mood / wish / custom text;
3. скрытие блока wishes + Share до нового выбора mood;
4. краткая задержка, затем phase снова idle (когда блок снова появится).

Share **без сети**. Ошибки только inline у custom field, **не** alert/modal.

## 5.6 My mood this week

Контейнер — одна glass-карточка.

### Заголовок секции

- Иконка `calendar` + `MY MOOD THIS WEEK` — не кнопка.

### Кнопки дней (7)

Последний слот всегда `Today`.

| День | Вид сферы | Тап |
|------|-----------|-----|
| Есть mood(s) | Микро-сфера последнего mood; badge `N` если N>1 | Toggle раскрытия деталей внутри карточки |
| Выбранный (expanded) | Мягкий glow / акцент ring цветом mood | Повторный тап сворачивает |
| Пустой | Пунктирный круг + `?` | **disabled** / ничего не открывает |

Под сферой — лейбл дня (`Thu`… / `Today`).

### Детали дня (внутри карточки, не отдельный modal поверх экрана)

| Элемент | Требование |
|---------|------------|
| Header | Слева лейбл дня, справа `N mood` / `N moods` |
| Строка | Не кнопка: tinted bar · иконка · короткий label · полное name · время `HH:mm` |
| Скролл строк | Если ≥ **3** записей — вертикальный scroll внутри фиксированной высоты |
| Автоскролл страницы | При открытии дня — чуть вниз, чтобы детали были над tab bar |

Seed-данные недели допустимы для demo.

## 5.7 Floating tab bar (контекст Me)

| Элемент | Требование |
|---------|------------|
| Вкладки | Me · Partner · Us · Connection · More |
| Активная | Me — тёмный icon/label + индикатор |
| Поведение | Переключение табов; Me content unmount/remount не должен терять session store |
| Клавиатура | Tab bar можно скрывать, пока открыта клавиатура на Me |

# 6. Сценарии страницы (acceptance)

1. **Cold open Me** — greeting, empty/seed current, 6 сфер, week strip; wishes/Share скрыты.
2. **Select Calm** — wishes Calm видны; Share видна; ambient tint Calm; другие сферы dim.
3. **Select preset wish → Share** — Sending → Sent! → current обновлён; выбор сброшен; день Today в week обновлён.
4. **Custom wish invalid → Share** — ошибка под полем; share не уходит.
5. **Deselect mood** — wishes/Share скрыты.
6. **Tap week day with entries** — in-card list; empty day не открывается.
7. **Partner reacted** — chip + note на current; тап панели → dialogue sheet.

# 7. Поле: Me → своё wish

**Где:** блок wishes. **Placeholder:** `Or write your own…`

### Назначение

Либо пресет, либо свой текст. Без wish Share не завершает отправку успешно.

### Допустимые символы

| Тип | Разрешено |
|-----|-----------|
| Буквы | Латиница `A–Z` `a–z` |
| Цифры | `0–9` |
| Пробел | да (переносы строк → пробел) |
| Пунктуация | `.` `,` `!` `?` `-` `:` `"` `'` + smart quotes iOS |
| Emoji | да (skin tone / ZWJ) |

Иначе — недопустимо. Пресеты каталога этим алфавитом **не** проверяются.

### Длина

- Max **80**; жёсткий стоп ввода/вставки.
- Счётчик `N/80`; у лимита — цветовой акцент.

### Валидация (только по тапу Share)

| Случай | UI |
|--------|-----|
| Нет пресета и пустой custom | Inline ошибка + красная обводка custom field |
| Недопустимые символы в custom | Inline ошибка + красная обводка |
| OK | Share sequence |

Редактирование поля или выбор пресета **снимает** ошибку.

### Поведение

- Пресет → очищает custom.
- Ввод custom → этот текст = selected wish.
- Смена/сброс mood → очищает wish и custom.

# 8. Поле: Partner → Add a note to their mood

**Где:** Partner, composer реакции на hero.  
**Плейсхолдер:** `Add a note to their mood…`

Связь с Me: входящая реакция/note партнёра показываются на current-mood панели Me (§5.1).

### Допустимые символы

| Тип | Разрешено |
|-----|-----------|
| Буквы | Только латиница `A–Z` `a–z` |
| Цифры | `0–9` |
| Знаки препинания | `.` `,` `!` `?` `:` `-` |
| Пробел | да (но не как единственное содержимое — см. ниже) |
| Emoji | да |

Всё остальное (кириллица, кавычки, прочие символы) — **недопустимо**.

### Ограничения длины

- Максимум **60** символов.
- После 60 новые символы не добавляются.
- Счётчик `N/60` у поля.

### Отправка реакции (одна кнопка Send)

| Правило | Поведение |
|---------|-----------|
| Emoji обязателен | Нельзя отправить без выбранной emoji-реакции → **alert под полем** |
| Note опциональна | Можно отправить **только emoji** (поле пустое) |
| Только пробелы | Нельзя: поле с одними пробелами → **alert под полем** |
| Недопустимые символы | Alert под полем; отправка не выполняется |
| Отправка | **одна** кнопка `Send reaction` (нет Change / Update) |
| Один раз | На текущий mood партнёра — **только одна** реакция; после отправки только просмотр |
| После успеха | «You reacted» (+ note, если был валидный текст); смена реакции недоступна |
| Новый mood партнёра | Слот реакции сбрасывается — можно отреагировать снова |

Все алерты — **inline под полем ввода** note (не модальное окно).

### Клавиатура

- При фокусе на `Add a note to their mood…` экран скроллит так, чтобы поле (и кнопка Send) оставались **над** клавиатурой.
- Закрытие: кнопка **Done** на toolbar клавиатуры, submit на поле, Cancel / Send, свайп по скроллу (`scrollDismissesKeyboard`).
- Floating tab bar скрывается, пока клавиатура открыта (как на Me).

### Тексты алертов (под полем)

- Нет emoji: `Choose an emoji reaction before sending.`
- Только пробелы: `Note can’t be only spaces. Add text or leave the field empty.`
- Недопустимые символы / длина: `Only Latin letters, numbers, punctuation (.,!?:-), spaces, and emoji. Max 60 characters.`
